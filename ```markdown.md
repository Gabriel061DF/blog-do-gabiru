
# ☩ Blog do Gabiru

Meu primeiro projeto web pessoal.

Um espaço para registrar pensamentos, aprendizados,
experiências, projetos e minha evolução.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 🎨 Estilo

O projeto possui uma identidade visual inspirada em:

- Estética gótica
- Medieval
- Sombria
- Minimalista

## 🚀 Objetivo

Este projeto faz parte da minha jornada de aprendizado
em programação e desenvolvimento web.

A ideia é continuar evoluindo o projeto conforme novos
conhecimentos forem adquiridos.
